# Домашнее задание 5

- `src/dictionary.ts` — словарь на префиксном дереве (Trie): добавление и проверка слова O(33 * L), память 11 * P байт, P <= N
- `bench.ts` — замер на настоящем словаре

Установка:

```bash
bun install
```

Запуск (меню, данные вводятся с клавиатуры):

```bash
bun run index.ts
```

Тесты:

```bash
bun test
```

Замер (файл по одному слову на строку, UTF-8):

```bash
bun run bench.ts words.txt
```
